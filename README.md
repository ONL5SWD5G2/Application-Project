# Student Quiz Application

A beginner-friendly quiz application built with HTML, CSS, Bootstrap, and vanilla JavaScript.

## How to run

Open the project with Live Server, then visit `index.html`. Live Server is needed because the quiz loads its questions from a JSON file using the Fetch API.

## Features

- Student registration and login using Local Storage
- Protected quiz and result pages
- Ten web development questions loaded from a JSON file
- Score, percentage, and pass or fail result
- Try again and logout actions
